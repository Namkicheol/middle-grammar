# 게임 개선 순서 — 2026-09-12

사용자 지시: 구현은 Luna xhigh, 상위 에이전트는 범위 지휘·결과 검수. 대화 중 추가 지시가 와도 진행을 중단하지 않는다. 멀티 연결은 마지막이다.

## 순서와 수용 기준

1. **태블릿 화면 잘림 — 로컬 검증 완료**
   - 교실 게임 외부 UI와 내부 Tower 높이를 함께 조정.
   - 1280×650, 1024×600, 800×1100, 390×844 실제 브라우저 확인.
   - 1024×600에서 순위 5행 펼침: iframe 높이 408px, 마지막 답 아래 380px. 마지막 답 클릭이 부모 submitAnswer까지 전달됨.
   - Tower 회귀, classroom layout 계약 테스트, 학생 사용성 검토 통과.
   - 테스트는 로컬 ClassroomHost fixture이며 실제 다인 경기·태블릿 하드웨어 검증과 구분한다.
2. **게임 홈 — 로컬 검증 완료**
   - 큰 게임 그림과 최소한의 제목 중심. 선택 후 학년·주제 설정.
   - 기존 7개 솔로 경로·랜덤 선택·멀티 진입 보존. 학습지 루트 홈은 변경하지 않는다.
   - 1024px 화면 카드 폭 230.5px, 390px 화면 174.5px. 초기 설정 숨김, 선택 후 설정 표시, 가로 넘침 없음 확인.
3. **블록블라스트 효과·소리 — 로컬 검증 완료**
   - 효과 이름·영향·지속시간을 읽을 수 있게 표시. 화면 효과가 입력을 막지 않게 한다.
   - 효과별 구분되는 소리, 음소거 유지, 기존 점수·문항 전환 회귀 검사.
   - 390px 브라우저: 13px 지속 효과 설명, SUPER 색상 구분, 1.3초 연출, 넘침 없음. 상태·효과 회귀 및 학생 검토 통과. 소리는 코드 검증이며 청음 완료로 간주하지 않는다.
4. **공포 방탈출 솔로 — 로컬 검증 완료**
   - GPT 이미지 기반 배경·에셋, 긴장감 있는 BGM·효과음.
   - 탐색→퍼즐→열쇠→탈출, 방향키/WASD 및 터치 방향패드 미로.
   - 중학생 대상: 고어·과도한 섬광·갑작스러운 고음 비명 제외.
   - 상용 품질 목표: 통일된 아트, 읽히는 UI, 조작 피드백, 성능·재시작 검수.
   - 에셋 생성 경위는 `escape/assets/ASSETS.md`에 기록. 상용 출시의 권리·품질 검토와 구분한다.
   - `escape/` 구현. GPT 배경 3종·캐릭터 1종, 원본 합성 사운드, 3장 흐름.
   - 실제 브라우저: 528 잠금→상대순서 퍼즐→터치 이동→21걸음 키보드 탈출→성공 화면, 초기화 및 음소거 저장 확인. 헤더 겹침 없음. 학생 검토는 현재 범위 수용, 상용 출시 판정은 아니다.
5. **방탈출 멀티 UI 연결 — 로컬 검증 완료, 마지막**
   - 솔로 수용 후 기존 서버 규약에 새 UI 연결. 실제 다중 클라이언트·재접속·종료·결과 검수는 별도 잔여 항목.
   - 나머지 신규 게임 2종 개선은 보류.
   - 기존 서버는 탐색/3자리 잠금/문법 탐색력 규약이다. 서버 판정은 유지하고 새 장면·조작 UI를 연결한다. 방향키 미로는 이번 솔로 구현이며 멀티 서버 이동 규칙까지 확장하지 않는다.
   - 로컬 브라우저 fixture에서 inspect 요청, 서버 단서/seq 반영, unlock 요청, stale 오류 상태 복구, 미발견 단서의 오프라인 비활성화 확인. 390px/1024px 가로 넘침 없음.
   - Worker 배포 디렉터리 안의 배경 3종·오디오 사본 경로 HTTP 200 및 원본 바이트 일치 확인. 실제 운영 배포 확인은 아니다.
   - 멀티 UI 회귀, 서버 escape 단위 테스트 3개, 오디오 lifecycle 통과. 학생 재검수 ACCEPT: 방 2·3 잠금 순서 표시, 상단 문제 CTA, focus 0 안내, 단일 열 공포 배경 확인.
   - 브라우저에서 방 2 `☾ → ☀ → ✦`, 방 3 `☀ → ✦ → ☾` 출력 확인. 완료 snapshot에서 문제 숨김·배경음 중단 확인. 실제 다인/실기기 경기와 청음은 미검증.

## 별도 반영
