# 문법 카트 — 맵·랩·아이템 개선

## 요청과 작업 기준

- 사용자가 Terra 6.1 구현, 상위 에이전트의 지휘·최종 검수를 요청했다.
- 작업본: 현재 운영 배포 dpl_Ad7zWFWxvhxXLRx6E8QnuhTA6JXN의 소스(687cab8 + 문제 패널 개선 6개 파일)를 복원한 독립 worktree.
- 현재 범위는 사용자가 보고 있는 솔로 레이싱 화면과 엔진이다. 서버가 판단하는 교실 레이스의 규칙을 솔로 코드로 덮어쓰지 않는다.
- 별도 배포·커밋·푸시 없이 구현과 검수를 완료한다.

## 구현 결정

1. 맵 선택을 색상 카드로 강조한다. 기존 coastal/hill에 neon/snow를 추가한다. 단순 이름만 바꾸지 않고 도로 굴곡·주변 색·장식으로 구분한다.
2. 기본 3랩(랩당 1800m), 1/3/5랩을 선택할 수 있게 한다. HUD·결과·기록 저장은 랩 수를 반영한다. 과거 1랩 기록을 3랩 기록과 비교하지 않는다.
3. 출발 그리드의 앞뒤·좌우 간격을 넓힌다. 사용자 정정에 따라 **문제 풀이 중에도 상대 카트와 충돌할 수 있다.** 문제 구간 전체를 무적으로 만들지 않는다.
4. 사용자 재정정에 따라 **답을 고르는 판정선 바로 주변만 고정 장애물을 제거**한다. 정답 레인만 비우면 정답을 노출하므로 판정선 주변 네 레인을 함께 비운다. 문제를 읽으며 달리는 구간의 장애물과 카트 경쟁은 유지한다.
5. 일반 속도 약 7.5% 상향(40→43), 부스트도 비슷한 비율로 조정한다. AI도 균형을 맞춘다.
6. 장애물 종류·아이템 상자 보상을 늘린다. 미사일은 앞차를 향해 발사·비행·피격한다. 얼음 아이템은 앞차를 짧게 감속시키고 시각적으로 얼린다. 대상이 없으면 소모하지 않고, 방어막으로 막을 수 있게 한다.
7. 기존 9개 캐릭터, 음악·음소거, 문제·보기의 트랙 외 고정 패널을 유지한다.

## 파일 책임과 계약

- Terra engine: grammar-kart/solo-race.js 및 엔진 회귀 테스트.
- Terra UI: solo-app.js, solo-style.css, solo-race-skin.css, grandprix.css, index.html, 필요한 결과 화면.
- 공통: options.laps 기본 3. 맵 ID coastal/hill/neon/snow. state.total/lap/laps/lapDistance/frozen 및 heldItem='ice'. useWeapon('ice').
- 기존 교실용 race.js/multi.js 및 Worker는 기능 변경 대상에서 제외하고 로드·격리만 확인한다.

## 검증 기준

- 3랩으로 실제 5400m에서 종료, 2·3랩에도 문제·장애물·아이템 반복, 랩별 미니맵·기록 일치.
- 판정선 안전 범위의 고정 장애물 없음, 읽는 구간의 장애물 유지, 문제 중 상대 카트 충돌 가능.
- 출발 그리드의 과도한 겹침 감소.
- 미사일/얼음의 정상 획득→사용→재고 변화→앞차 효과, 대상 없음·방어막 경계.
- 네 맵이 실제 색·굴곡 차이를 보이고 맵·랩 선택이 유지됨.
- 390×844, 390×667, 844×390, PC에서 문제·트랙 비겹침, 44px 버튼, 빈 재고·오류 없는 동작.
- 학생 관점 독립 검토와 상위 Aside 실제 화면 검수. 모의 fixture와 실제 기기 검증을 구분해 보고.
