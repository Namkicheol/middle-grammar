### 최종 사용자 기준 반영

- 사용자가 전날 직접 제시한 답안 화면을 기준으로 `game/question-surface.css`는 기존 재질·글꼴을 그대로 복원했다. 단순 흰 카드 시안은 배포 대상에서 제외한다.
- 두더지는 사용자가 좋아한 기존 사이버 배경·굴·네온 캐릭터를 유지하고 상단 패널의 진행/타이머 잘림과 최고점 배지 겹침만 보정했다. 새 공원/캐비닛과 생성 캐릭터는 최종 반영하지 않는다. 실제 정답→다음 문항·100점, 390px 비넘침·카드 내부 타이머 확인. [최종 두더지](whack-cyber-panel-390.png).
- 실제 솔로 7종은 보스전·스피드·두더지·보글보글·탑·레인저스·블록이다. 허브에서 보스전은 game2로 이동한다. 예전 game 내부 보스 화면을 별도 게임으로 세지 않는다.
- 보스전에서 재도전 시 이전 문제창이 남는 버그를 발견해 G.start에서 기존 cancelTimers를 먼저 실행한다. 이전 문제 열린 상태→제어한 패배→실제 재도전에서 문제창 닫힘·양쪽 HP100, 다음 공격의 새 문제와 활성 선택지 확인. 첫 사용법은 질문 팝업 중 숨긴다.
- 탑·레인저스: 390px/데스크톱 비넘침, 실제 정답→새 문제, 제어한 종료→재시도, 목록 취소→진행 유지와 확인→허브 이동. 레인저스 안내 단어 분리와 기력 값 대비 수정.
- 보글보글: 390px 실제 발사→8발 문법 찬스→정답→강화 상태→제어한 종료→실제 다시풀기→메뉴 확인. 스피드: 실제 정답→100점/콤보1/다음 문제, 원래 재질형 답안과 선택지 대비 확인. [보글보글](bubble-material-390.png) · [스피드](speed-material-390.png).
- 블록: 새 판/대기칸 배치와 기존 재질형 문제창을 함께 사용한다. 실제 pointer drag 배치, 제어한 scramble 정답·피드백 후 다음 문제 answer-zone 0개, 종료→재시도→64셀 재생성, 390px 비넘침 확인. 상태 회귀와 교실 어댑터 검사 통과. [블록 판](blast-board-final-390.png).
- 학생 관점 교차 검토는 구현하지 않은 담당자가 체크리스트로 별도 수행했다. 지적된 스피드 답안 대비, 블록 작은 안내문, 보스 안내문 가림을 수정했다. 로비 검은 캡슐은 full-page 캡처 경계 인공물임을 DOM 대조와 단일 viewport 재캡처로 확인했다.
- 범위: 직접 사용자 조작과 제어된 상태 전이를 조합했다. 모든 자연 종료 완주나 실제 학급 다중 기기 부하를 보증하는 검증은 아니다.

- 서체: 일반 고딕으로만 바뀐 게임 UI에 대한 추가 피드백을 반영해 제목·HUD·게임 제어에는 자체 호스팅 Galmuri11을 사용한다. 문제와 답안은 기존 서체를 보존한다. 공식 quiple/galmuri의 WOFF2와 SIL OFL 1.1 원문을 함께 포함했다. 고유 글자 크기는 유지하고 굵기 합성은 하지 않는다. [공식 출처](https://github.com/quiple/galmuri).
