# 2026-09-08 아케이드 재구성 · 검증 기록

## 범위와 책임

사용자 요청: 기존 멀티 3종 게임 규칙과 UI 재구성, 솔로 버그 수정, 전체 솔로의 교실 경쟁 지원, 교사 문제 입력 개선. 후속 우선순위는 블록 블라스트 버그 수정이다. 기획·규칙·최종 수락은 주 에이전트, 파일별 구현·독립 검증은 하위 모델이 맡는다. 기존 미커밋 변경을 보존하며 배포·커밋은 이 작업에 포함하지 않았다.

## 확정 게임 계획

- 금고: 정답으로 액션 획득 → 보물 확보/위험을 공개하는 추가 탐색/대상 약탈. 3정답마다 점수 교환권 1개까지 충전. 교환은 실제 점수에 적용하며 방패·팀 보호·중복 요청 방지 적용. 교사가 약탈/교환 허용을 선택한다.
- 미궁: 전체 경로를 보며 보물 선점 → 운반 → 안전 본진 귀환. 운반 중 보물은 상대가 가로챌 수 있다. 본진 보호·팀 보호·쌍별 재약탈 제한·8초 보물 재등장을 적용한다. 확보한 보물이 순위에 실질적으로 반영되어야 한다.
- 탈출: 전력실 퓨즈 → 자료실 단서 타일 순서 → 현관 회전 다이얼. 같은 암호 계약을 사용하되 서로 다른 장치를 직접 조작한다. 발견한 단서는 보존하고 팀의 방 진행을 동기화한다.
- 디자인: 밝은 민트/연보라 배경과 게임별 새 3D 일러스트, 큰 터치 카드. 게임 중에는 장면·현재 목표·액션 우선. 제품 비교 문구 제거.

## 블록 블라스트 확인 완료

- 실제 Aside 페이지에서 순서배열/선택형 12회 전환: 선택한 단어·답안 영역 잔류 없음.
- 실제 단어 버튼을 순서대로 눌러 정답 제출: +500, 선택 배열·원본 칩·답안 영역 모두 0으로 초기화.
- 브라우저에서 제어된 상태 회귀: 빈 답 제출 방지, 시간초과 후 계속, 이전 정답 지연 콜백이 새 문제를 닫지 않음, 드래그 취소가 블록을 배치하지 않음, 문제 전환 시 드래그 잔상 제거, 종료 시 챌린지 닫힘.
- 실제 `한 판 더`: score/grammarTotal/chosen=0, phase=play, 단원 유지.
- 독립 학생 점검: 390×844에서 블록 블라스트 포함 솔로 7종 단원 전달·실행·가로 넘침·콘솔 오류 검사 통과. 모든 게임의 자연 종료를 완주했다는 뜻은 아니다.

## 다른 발견

- 스피드 퀴즈의 다음 문제 timeout이 홈/재시작 뒤 살아남을 수 있어 clearSpeedTimer에서 함께 해제하도록 수정.
- 무한의 탑·레인저스 활성 게임에 목록 복귀를 추가했다. 취소하면 진행 상태를 유지하고 교실 모드에서는 숨긴다. 390px HUD 겹침과 복귀 동작을 확인했다.
- 다른 방 링크에서 이전 방 학생 정보를 복원하려는 문제를 방 코드별 복원으로 수정했다. 같은 방 재접속은 유지한다.
- 스피드 퀴즈에 5연속 정답으로 충전하는 더블 찬스를 추가했다. 사용 시 다음 정답 보상 2배, 오답 시 소모, 재시작 초기화를 확인했다.

## 배포 범위

이 기록의 테스트는 로컬 개발 서버와 로컬 Worker 기준이다. 후속 사용자 지시로 커밋·푸시·Vercel과 멀티 서버 배포가 승인되었다. 배포 준비 시 Vercel 인증은 확인했고 Cloudflare CLI는 로그인이 필요했다. 새 인증 코드 배포 전에 원격 D1 `0006_teacher_moderation.sql` 적용이 필수다. 실제 다수 학생 네트워크 부하와 모든 게임의 자연 종료 완주는 검증 범위에 포함되지 않는다.

## 추가 요청 · 확인

- 1·2·3위 시상대를 밝은 챔피언 무대로 재구성했다. 390px에서 0/1/2/3명·공동 순위·긴 이름·9자리 점수·팀전·탈출 기록에 가로 넘침과 참가자 겹침이 없었다. 3→2→1 공개와 키보드 음소거 조작 확인. [모바일](results-new-390.png) · [데스크톱](results-new-desktop.png).
- 교사 객관식 입력을 보기별 정답 선택 방식으로 단순화했다. 선택지 2개 시작·최대 4개·정답 라디오·정답 입력형 전환·작성 내용 유지·편집·가져오기·문자열 HTML 이스케이프·저장 후 복원을 실제 390px에서 확인했다. [문제 입력창](creator-easy-390.png).
- 교사 가입·로그인 문구를 명확히 하고 관리자 전용 계정 목록·검색·상태 필터·차단/해제를 추가했다. `google_sub` 기준 차단, 세션 폐기, 차단 후 새 로그인 거부, 해제 후 과거 세션 비복구, 본인/관리자 보호, 폐기 실패 재시도를 서버에서 검증했다.
- 격리된 로컬 Worker에 더미 계정을 만들어 관리자 화면에서 차단/해제 후 API 재조회, 일반 교사 403, 50개 페이지네이션, 밑줄이 있는 이메일의 문자 그대로 검색, 390px dialog 비넘침을 확인했다. 이후 작은 링크 두 개의 터치 높이를 44px로 보완했다. 실제 계정은 차단하지 않았다.
- `/`·`/multiplayer`는 `/multiplayer/`로 이동하고 `/multiplayer/`와 상대 JS/CSS가 연결되도록 고쳤다. 운영의 가입 복귀 경로 404를 해결하기 위한 변경이다.
