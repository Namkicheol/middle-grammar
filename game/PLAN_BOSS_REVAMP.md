# 문법 보스전 리뉴얼 — 멋지게 v2

## 비전
"MCQ 정답 → 자동 공격" 한 줄짜리 게임플레이를, **단계별 변신 + 고유 필살기 + 텔레그래프 액션 레이어**가 있는 보스 러시로 끌어올린다. 기존 Phaser 씬·SVG 포트레이트·콤보/스킬 게이지·BGM은 그대로 살리고, 그 위에 단계 시스템·시네마틱·텔레그래프를 얹는 incremental 방식.

## 단계 사양

### Lv.1 학생 (현재)
- 무기: 연필 / 오라: 없음
- 필살기: **연필 슈팅 스타** — 가로 광선 1발, 카메라 셰이크 small
- 패시브: 없음

### Lv.2 마법사 학자
- 무기: 책 지팡이 (펼친 페이지가 주위에 떠다님) / 오라: 청-금 글로우 링
- 필살기: **문장 폭풍** — 책 펼치며 페이지 회오리, 3타 멀티히트, 카메라 zoom-in + medium 셰이크
- 패시브: 콤보 게이지 충전 1.4배

### Lv.3 영웅 각성
- 무기: 거대 문법 검 (잔상 트레일) / 오라: 흰빛 후광 + 빛 날개
- 필살기: **문법 심판** — 화면 분할 일자 베기, 보스 화면 밖 fly-off, 카메라 zoom-out + 화이트 플래시
- 패시브: 보스 텔레그래프 표시 + 0.4s 카운터 윈도우 (탭 시 회피+반격)

## 보스 폼

| Lv | 이름 | 색·크기 | 새 패턴 |
|----|------|---------|---------|
| 1 | 문법 보스 | 빨강-보라, 1.0× | 단순 반격 (현재) |
| 2 | 분노한 마왕 | 어두운 빨강 + 화염 파티클, 1.1× | **텔레그래프 차징** (5초 안 정답 못하면 피격) |
| 3 | 진짜 마왕 | 검정-보라 + 보랏빛 균열, 1.3× | 빠른 텔레그래프 (3초) + 광역 패턴 |

## 단계 전환 시네마틱
Lv.2/Lv.3 시작 시:
1. 화면 전체 검은 오버레이 + 카메라 화이트 플래시
2. 새 캐릭터 포트레이트 중앙 큰 크기 등장 (1.2s)
3. 타이포 "STAGE 2 — 마법사 각성" 슬라이드인
4. 새 보스 이름 등장
5. BGM 한 톤 더 비장하게 크로스페이드

## 텔레그래프 (Lv.2+)
- 보스 머리 위 차징 바, Lv.2: 5초 / Lv.3: 3초
- 차징 동안 정답 → 보스 공격 무효화 + 평타
- 차징 만료 → 보스 공격 발동, 플레이어 피격
- Lv.3 패시브 보유 시 발동 직전 0.4s "패링" 버튼 → 탭하면 회피+반격

## 작업 단계
1. **데이터 레이어** — `HERO_FORMS`, `BOSS_FORMS`, `ULTIMATES_BY_LEVEL` + 헬퍼.
2. **포트레이트 SVG 3폼** — HUD 영웅/보스 SVG 단계별 교체.
3. **Phaser 시각 업그레이드** — 단계별 tint/오라/무기 오버레이, `BossFightScene.setForm(level)`.
4. **필살기 3종** — `castUltimate(level)` 분기, 각자 고유 particle/카메라/사운드.
5. **단계 전환 컷씬** — `playStageCutscene(newLevel)`.
6. **텔레그래프** — 차징 바 + 타이머, 정답 처리와 통합.
7. **카운터 윈도우** — Lv.3 패시브.
8. **발란싱 + QA** — HP/데미지/시간, 모바일 터치 응답.
