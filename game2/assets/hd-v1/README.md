# Grammar Boss Battle HD v1

Project-specific 2D game art generated with OpenAI image generation in July 2026.

- Mode: new image generation plus identity-preserving edits for the hero's tier upgrades.
- Hero line: Moonblade Ranger, Nebula Spellblade, Phoenix Moon Paladin.
- Boss roster: Ironmask Jester, Bloom Colossus, Bone Samurai, Void Manta, Rift Sorceress, Obsidian Dragonlord.
- Direction: original side-view fantasy fighters, polished cel shading, clear small-scale silhouettes, no text or UI.
- Hero faces right; bosses face left.
- Cutouts were generated on green or magenta chroma backgrounds, converted to transparent PNG, cropped, and fitted to uniform 512px runtime canvases.
- `arena.png` is the original moonlit celestial coliseum background.

Chroma-key source renders are kept in `source/` for later reprocessing.
