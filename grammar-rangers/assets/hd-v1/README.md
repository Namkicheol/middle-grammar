# Grammar Rangers HD v1

Project-specific 2D game art generated with OpenAI image generation in July 2026.

- Mode: new image generation with the earlier premium hero/goblin concept used only as a rendering-quality reference.
- Direction: original side-view fantasy characters, polished cel shading, strong small-scale silhouettes, no text or UI.
- Allies face right; enemies face left.
- Character and cannon cutouts were generated on flat green or magenta chroma backgrounds, converted to transparent PNG, then cropped and resized for real-time Canvas rendering.
- `battlefield.png` is a wide original battlefield background with blue and red fortresses at opposite edges.

Runtime assets live in `units/`, `cannon.png`, and `battlefield.png`. Chroma-key source renders are kept in `source/` for later reprocessing.

July 2026 unit expansion: `rock-giant`, `arcane-catapult`, `battle-priest`, `rift-warlock`, `castle-marksman`, `abyss-warlord`, and `crimson-dragon-tyrant` were generated as original project-specific cutouts with the same pipeline.
